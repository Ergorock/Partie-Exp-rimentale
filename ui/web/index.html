          Paramètres des règles RMN

          Multiplicités reconnues

          À gauche ce qui est écrit dans le document, à droite ce qui sera écrit à la place. Une multiplicité absente de cette liste (ddq…) est signalée sans être modifiée.

          ÉcritDevientRetirer
          Solvants RMN

          À gauche ce qui est écrit dans le document (sans tenir compte de la casse), à droite ce qui sera écrit à la place. Entourez de * le texte à mettre en italique (DMSO-*d*6) ; les indices des chiffres sont ajoutés automatiquement. Un solvant absent de cette liste est signalé sans être remplacé.

          Évaluation

          Note obtenue selon le pourcentage de sections déjà conformes. Seuils décroissants entre 0 et 100 ; en dessous de « Correct », la note est « Mauvais ».
